## Funcionalidades Implementadas

1. **Contador de Reservas**

   * A cada clique no botão "Alugar agora", o sistema contabiliza uma nova reserva e atualiza o total exibido na página.

2. **Último Veículo Reservado**

   * O sistema identifica qual veículo foi reservado por último e exibe seu nome dinamicamente na tela.

## Tecnologias Utilizadas

* HTML5
* CSS3
* Bootstrap 5
* JavaScript

## Objetivo do Projeto

Desenvolver uma página web para uma locadora de veículos utilizando HTML, CSS, Bootstrap e JavaScript, aplicando conceitos de interatividade, eventos e manipulação do DOM.
